# Simple Calculator (Python)

## Overview

This is a simple command-line calculator built using Python. It performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

## Requirements

* No external modules are required.
* Uses only basic Python functions and standard input/output.

## Features

* Addition of two numbers
* Subtraction of two numbers
* Multiplication of two numbers
* Division with zero-division handling

## How It Works

1. The program displays a list of operations (Add, Subtract, Multiply, Divide).
2. The user selects an operation by entering a number (1–4).
3. The user inputs two numbers.
4. The program performs the selected operation.
5. The result is displayed.
6. Handles invalid inputs and division by zero.

## How to Run

```bash
python calculator.py
```
